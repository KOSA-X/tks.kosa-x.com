# KOSA X CMS

Autorski system CMS do szybkiego tworzenia stron internetowych.

## Stack
- PHP 8.0+
- SQLite
- SCSS/CSS (Prepros)
- Vanilla JS

## Zależności zewnętrzne
- jQuery 3.7.1
- PHPMailer 7.0.2
- Owl Carousel
- Fancybox

## Struktura
```
/core/          - Silnik CMS
/database/      - Baza SQLite + config
/plugins/       - Moduły (sklep, formularze, etc.)
/templates/     - Szablony (theme + admin)
```

## Setup
1. Skopiuj pliki na serwer
2. Ustaw chmod 755 na `/database/`
3. Panel admin: `/adm.php`
